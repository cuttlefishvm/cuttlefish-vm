pub fn dimensions(bytes: &[u8]) -> Result<Value, String>
Expand description

Pixel dimensions, read from whichever header the format keeps them in.

Cheap enough to run on every file in a corpus, and it is the single most useful fact about an image after its format — a “photo” that is 1x1 is a tracking pixel, and one whose dimensions disagree with its EXIF has been re-encoded or tampered with.
