pub fn read_signature(engine: &Engine, module_bytes: &[u8]) -> Result<Signature>
Expand description

Read a block’s declared signature out of a compiled module.

Instantiates the module and calls its cf_signature export. That is heavier than parsing a sidecar file, and it is the point: the answer comes from the artifact that will actually run, so it cannot describe a different version of the block than the one being checked.

A block built before signatures existed has no such export. That is not an error — it reports the permissive default, so an older block still composes, just without the seam being checked.
