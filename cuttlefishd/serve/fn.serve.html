pub async fn serve(
    app: Router,
    endpoint: &Path,
    shutdown: impl Future<Output = ()> + Send + 'static,
) -> Result<()>
Expand description

Serve app on endpoint until shutdown resolves.

endpoint is a socket path on unix and a pipe name (\\.\pipe\...) on Windows; see cuttlefish_core::endpoint::default_endpoint. shutdown is the portable stand-in for a SIGTERM handler — Windows has no signal this daemon could install one for, so graceful stop is instead triggered by the POST /shutdown route resolving this future; see api::AppState.
